# Seguridad

## Informar de una vulnerabilidad

Usa el formulario privado de GitHub:
**[Security › Report a vulnerability](https://github.com/Hades0413/GamePadMapperPluton/security/advisories/new)**.

No publiques los detalles en issues, pull requests ni redes hasta que haya una versión corregida.
Incluye, si puedes, la versión afectada, los pasos para reproducirlo y el impacto.

Responderemos lo antes posible y te avisaremos cuando la corrección esté publicada.

## Versiones con soporte

Solo la última versión publicada (Google Play y el último Release de GitHub) recibe correcciones.

## Alcance

- App Android `com.gamepadmapper.app` y el módulo root `gamepad_mapper`.
- Web y base de datos de perfiles de la comunidad (`web/`, `supabase/`).
- Flujos de compilación y publicación (`.github/workflows/`).
